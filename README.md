# HackBS-A-tool-for-the-infamous-Game-stimulation-clicker-on-neal.fun

HackBS is a tool for the Game stimulation clicker. With this tool, you can earn a lot of points at one time

Getting Started:

1. Open the game at "https://neal.fun/stimulation-clicker/"
2. Open File explorer and extract the downloaded Folder
3. Launch the "hack.vbs" file and quickly close the file explorer and all the other windows so you accidentally not open like that a lot of windows and different files
4. Enjoy!
